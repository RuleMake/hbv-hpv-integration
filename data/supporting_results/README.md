# External-catalogue comparisons

These tables report comparisons using the CLCA and Sasa catalogues, the HTLV-1
comparator and VISDB. They use an interval-and-endpoint representation, whereas
Supplemental Tables S1–S6 use paired structural-variant calls. Their null
distributions describe variation in spatial placement, rather than variability
between independently sampled donors.

Inputs for the figures are stored in their respective `figures/` directories.
Additional numerical sources are in `data/numeric_results/`; the files in
`provenance/` link reported values to those outputs.
