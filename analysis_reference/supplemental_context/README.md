# Supplemental context analyses

These sources cover additional analyses reported in the Supplemental Material: clonality and copy number, transcript and junction context, external liver datasets, genomic background and spatial robustness. The table below identifies each implementation and its role.

## Source files

| File | Purpose |
|---|---|
| `clonality_rebinning.py` | Rebins integration clonality by distance to the nearest structural rearrangement. |
| `direction_band_decomposition.py` | Examines clonality distance bands and copy-number/ploidy adjustment. |
| `timing_clonality_order.py` | Builds clonality and rearrangement-distance comparisons with sample-level controls. |
| `sasa_cis_orientation.py` | Analyzes viral orientation, viral breakpoint annotation and same-sample structural variants in the Sasa catalogue. |
| `integration_site_transcription.py` | Tests expression at integration-associated genes and nearby genomic contexts. |
| `junction_microhomology.py` | Scores junction microhomology from published sequence reads against a composition-matched null. |
| `mh_positive_control.py` | Evaluates the junction scorer with injected microhomology and sensitivity simulations. |
| `clca_amplicon_residency.py` | Measures same-sample integration residency in CLCA amplicon intervals. |
| `probe_clca_amplicon.py` | Parses CLCA amplicon intervals and summarizes the fields available for comparison. |
| `amplicon_class_specificity.py` | Compares integration residency across CLCA amplicon classes. |
| `ascertainment_bias.py` | Examines integration read support, local copy number and detection-related covariates. |
| `clonality_timing.py` | Builds junction-support and copy-number comparisons used by the amplicon analyses. |

| `hbv_sample_level_td_burden.py` | Compares large-duplication burden across HBV detection groups in liver samples. |

| `furuta_class_atlas.py` | Computes class-specific spatial enrichment for the Furuta non-tumour coordinates. |

## Inputs and dependencies

Required inputs include the Sasa, Wang, Furuta and CLCA published tables; primary integration and structural-variant catalogues; genomic annotations and liftover chains; published junction sequences; expression summaries; and saved Hi-C contact measurements. Some programs also read intermediate tables generated by other analyses in this directory. Inspect each script's path constants and the release input inventory before preparing a work tree.

Shared statistical helpers and the bigWig reader are in `../supporting_analyses/`. The references to `src.common.config` and `src.common.genome_features` in `ascertainment_bias.py` and `clonality_timing.py` remain external project dependencies; these upstream modules are not bundled here. Do not install an unrelated package named `src` as a substitute.

Configure the relative `source_project` paths before execution, with source inputs and generated outputs in separate locations. Release verification checks the source files without running these analyses.

## Reading the saved results

The corrected integration-count permutation implementation is `dose_permutation_erratum.py`; its permutation assignment is the one used for the reported inference. `wang2025_longread_classes.py` computes both whole-sample summaries and paired contrasts; these must be matched to their corresponding manuscript statements. The clonality and distance scripts describe structural context and do not by themselves establish insertion time.

The amplicon slope code elsewhere in `supporting_analyses/coamplification_slope_control_and_signflip.py` uses normal-based intervals. The current Figure 6 `prepare_sources.py` applies the manuscript's t-based interval calculation to the saved estimates and standard errors. Use that preparation step for the displayed interval rather than treating the source interval column as the current figure value.

The input inventory identifies bundled data and external dependencies needed to run these implementations.
