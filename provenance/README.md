# Data sources and numerical references

`input_index.csv` describes the study inputs, with available access links,
file hashes and notes on derived data. See `INPUT_INDEX_README.md` for the
access categories and replication-timing references.

`numeric_claim_source_map.csv` links selected values for paired calls, local
composition, replication timing and donor proportions to exact rows or fields
in the included analysis outputs. `current_result_register.csv` indexes all
rows of Supplemental Tables S1–S6. Supplemental Table S7 summarizes detection
thresholds; the definitions and checksums for all seven tables are in
`tables/TABLES.json`.

`numerical_file_sources.csv` records the source and released-file checksums.
Paths refer to files within this package. The root `release_manifest.json`
provides a complete file inventory.

The package includes processed results used in the figures and tables.
Raw sequencing data, complete external callsets and genomic tracks remain
available through their respective sources and access procedures.
