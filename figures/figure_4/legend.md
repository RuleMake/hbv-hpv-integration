**Figure 4. Viral integration catalogues differ in local structural-variant composition.** (*A*) Enrichment of deletions (DEL), duplications (DUP), inversions (INV) and translocations (TRA) within ±100 kb of integration clusters. Filled symbols show call-count enrichment, counting each call once per cluster while allowing it to contribute to different clusters. Open symbols show calibrated cluster-sign enrichment, based on the number of clusters whose counts exceed their own spatial-null means. The reference contains 152,235 paired calls from 1,902 donors; HPV and HBV share a vertical scale, whereas EBV uses a wider scale. Asterisks mark two-sided spatial P < 0.05 after Bonferroni correction across three viruses, four classes and two estimators (24 tests). (*B*) Local composition within nominal ±1-Mb neighbourhoods, using 150,204 paired calls from 1,849 donors without detected integration. Left, observed-minus-null breakend fractions for each class, averaged with equal cluster weights. Right, the corresponding displacement in the score (TRA + INV) − (DEL + DUP), with positive values indicating a relative increase in TRA + INV. (*C*) HBV-minus-HPV score-displacement contrasts using paired calls or calls grouped within donors by identical breakend coordinates and orientations. Density matching adds local breakpoint-density deciles to the genomic matching variables. Unadjusted two-sided spatial P values for genomic and density matching are 0.0004 and 0.0016 for paired calls, and 0.0003 and 0.0004 for grouped calls. B and C display 100 times the fraction or score displacement, in percentage points. Whiskers show 95% spatial reference ranges from 20,000 randomizations: observed counts divided by reversed null percentiles in A, and displacements minus reversed, centred null deviations in B and C. Total-score and contrast ranges use joint randomizations across classes.
